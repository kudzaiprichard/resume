The link above always serves the PDF from the newest release. To publish a new version, replace
`Kudzai_Matizirofa_CV.pdf` (keep the file name) and push to `main`: the
[release workflow](.github/workflows/release.yml) creates a new release with the PDF attached, and
the link (used by the portfolio's "download CV") picks it up immediately.
